**Wave 2b (all approved and merged):** every `*dbNotebook` method is implemented on notestore, and the matching workspace tests run on database notebooks:
- reads (List, Find, Browse, Snapshot, ChangesSince and the rest);

- mutations (move, duplicate, organize, edit groups, containers, metadata), each committed atomically as one revision;

- backup and bundle import through gitexport;
- the authority handoff port (state in migration `0018`);
- the purge core (`notestore.Rewrite`, `workspace/purge.go`, and the completeness test that scans every stored byte).
