ChatGPT web

  1. Open ChatGPT Plugins → + → Add custom MCP server.
  2. Enter the endpoint above. Choose OAuth and dynamic client registration (DCR); leave static client credentials empty.
  3. Create and install your personal connection, then sign in to {{$brand.Name}}.

Availability depends on your account and security settings. Each person creates their own connection. Local ZIP packages are for desktop clients.

OpenAI desktop / Codex

  1. Download {{.Instance.Name}} for Codex.
  2. Copy this prompt into Codex on the same computer. Your agent handles setup.

After setup, reopen Codex. In Plugins, select your personal marketplace, install the companion and sign in. Start a new chat.

Manual setup

Direct Codex CLI connection

Use this instead of the plugin if you only need MCP tools:

codex mcp add {{.MCPName}} --url '{{.Instance.Endpoint}}'
codex mcp login {{.MCPName}} --scopes notes:read,notes:write,data:read

If another instance uses this connection name, choose a different name.

Upgrade or uninstall

Ask your agent to run the installer from a fresh download to upgrade, then reopen Codex. To remove it, uninstall in Codex and ask your agent to run python3 install.py uninstall. Other plugins and OAuth credentials are preserved.

Claude

  1. Download {{.Instance.Name}} for Claude.
  2. In Claude, open Customize → Plugins and upload the custom plugin ZIP. Individual Pro and Max accounts are supported.
  3. Enable the plugin and sign in to its MCP connection. Start a new chat.

Claude’s cloud must be able to reach this HTTPS endpoint.

Claude Code

Extract the ZIP in a durable directory. From there:

claude plugin marketplace add .
claude plugin install {{.Instance.ID}}@{{.Instance.ID}}-local --scope user

Use /mcp to authenticate. The included README covers updates and uninstall.

Other MCP clients

Use Streamable HTTP, OAuth authorization code flow with S256 PKCE, dynamic client registration, and these scopes:

{
  "mcpServers": {
    "{{.MCPName}}": {"type": "http", "url": "{{.Instance.Endpoint}}"}
  }
}

Configuration syntax varies by client. This is a common example, not a claim that every client is tested.
